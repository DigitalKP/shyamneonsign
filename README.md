## 🚀 Key Features

- **⚡ Real-time Neon Customizer**:
  - Live interactive glow engine rendered with CSS text-shadow layering and CSS animations.
  - 4 distinct font choices: *Pacifico (script)*, *Sacramento (thin script)*, *Bebas Neue (bold block)*, and *Orbitron (modern)*.
  - 9 rich neon colors: Hot Pink, Electric Blue, Warm White, Lime Green, Orange, Purple, Red, Yellow, Ice Blue.
  - 3 tube glow styles: *Steady Glow*, *Flicker Animation*, and *Outline Tube*.
  - Environment simulator: Dark Room, Realistic Wall Texture, and Daylight ambient modes.
  - Size slider with responsive scaling and live character counter.

- **🎯 Direct-to-WhatsApp Lead Generation Engine**:
  - One-tap WhatsApp checkout transferring exact text, font, color, glow style, and sizing to WhatsApp business chat.
  - Floating Action Button (FAB) for instant inquiries.
  - Fast quotation request form that formats user inquiries directly into pre-filled WhatsApp messages.
  - Direct calling button (`tel:+919305561967`).

- **🔍 Top-Tier Local SEO Architecture**:
  - Validated **Schema.org `LocalBusiness`** JSON-LD structured data with geo-coordinates (`26.4679713, 80.3190628`), address, telephone, and social profiles.
  - Pre-rendered **Schema.org `FAQPage`** JSON-LD structured data for Google Search rich question snippets.
  - ICBM and Geo meta tags (`geo.region: IN-UP`, `geo.placename: Kanpur`).
  - Open Graph and Twitter Cards for rich link previews across social media and WhatsApp.
  - Dedicated `robots.txt` and `sitemap.xml`.

- **📱 Performance & Accessibility**:
  - 100% responsive mobile-first UI with sticky floating controls and safe-area inset support for modern mobile devices.
  - Zero heavy external JavaScript dependencies; ultra-fast vanilla JavaScript.
  - Respects `prefers-reduced-motion` for accessibility.
